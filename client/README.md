# 校园便利圈 · 小程序项目

本目录为校园便利圈微信小程序唯一项目（用户端 + 商家端合并）。完整说明（功能、架构、部署、常见问题）见仓库根目录 `README.md`。

## 快速开始

1. 微信开发者工具导入本目录，AppID：`wx1d1452c2f59ffa68`。
2. 云环境：`cloudbase-d6gny18wlbad9e070`。
3. 部署 `cloudfunctions/` 下全部云函数（右键 → 上传并部署：云端安装依赖）。
4. 云开发控制台创建数据库集合并配置管理员（`config` 集合 `admin` 文档）。

## 目录要点

- `pages/`：用户端页面；`pages/merchant/` 为商家端页面（管理员可见）。
- `custom-tab-bar/`：用户端自定义底部导航，含未读角标。
- `components/merchant-tabbar/`：商家端底部导航组件。
- `cloudfunctions/`：全部云函数，`admin` 承载商家端管理接口。
- `utils/`：公共 JS 与 WXS 模板函数。

## 常用操作

- 管理员入口：「我的 → 商家管理」（或「设置 → 商家端管理」）。
- 群发消息 / 发布管理 / 订单管理：商家端概览页快捷操作。
- 提现：用户端「我的 → 我的财务 → 提现」，商家端审批后人工打款。

> 维护提示：云函数改动后需重新部署；数据库字段变更注意与集合实际数据保持一致。

# 校园便利圈（campus-service-circle）

校园二手交易、失物招领、互助与工具一体的微信小程序，基于微信小程序云开发（CloudBase）。

## 项目结构

```
campus-service-circle/
├── client/     # 客户端（学生端）小程序
└── merchant/   # 商家端（管理端）小程序
```

两端共用同一个云环境：`cloudbase-d6gny18wlbad9e070`。

## 技术栈

- 微信小程序 + 云开发（云函数 / 云数据库 / 云存储）
- 微信云支付（统一下单 + 支付回调）
- 企业付款到零钱（提现）
- 订阅消息 / 站内消息

## 功能

### 客户端（client）

- 游客登录：无需学号即可浏览全部内容；发布、支付、接单、聊天、提现等操作需学号登录
- 学号登录（密码哈希存储）
- 二手市场：发布、购买（微信支付）、搜索、聊天
- 失物招领：发布、认领
- 校园互助：拼车、代取快递、找搭子、其他互助（接单 + 支付酬金）
- 消息中心：站内消息、未读角标
- 财务：余额、提现（企业付款到零钱）、提现记录
- 工具：校园地图（地点搜索与分类）

### 商家端（merchant）

- 仪表盘：交易额、订单、分类统计、近 30 天趋势
- 订单管理：筛选、搜索、详情
- 财务总览：流水、佣金、用户余额、提现记录
- 提现管理、用户管理
- 首页配置（banner / 公告）

## 本地运行

1. 用微信开发者工具分别导入 `client/` 和 `merchant/`。
2. 确保两个项目的云环境 ID 与 `app.js` 中的 `cloudbase-d6gny18wlbad9e070` 一致。
3. 将 `cloudfunctions/` 下的云函数逐个「上传并部署：云端安装依赖」。
4. 在云开发控制台 `config` 集合创建管理员文档：

```json
{
  "_id": "admin",
  "openidList": ["你的openid"]
}
```

5. （可选）在微信公众平台申请订阅消息模板，填入 `client/config/templateIds.js` 和 `sendMessage` 云函数。

详细部署步骤见 `docs/部署检查清单.md`（本地输出目录）。

## 支付与提现说明

- 下单：`pay` 云函数统一下单并原子占位商品，防止一物二卖。
- 回调：`payCallback` 云函数在数据库事务中完成「支付标记 + 订单创建 + 卖家入账」，幂等且可重试。
- 提现：`transfer` 云函数通过企业付款到零钱直接打款，严格金额校验，转账结果核实后才落账。

# 校园便利圈（Campus Service Circle）

校园一站式便民服务微信小程序，涵盖二手交易、失物招领、校园互助、校园工具与平台管理后台。项目基于微信小程序原生框架与微信云开发（CloudBase）构建，用户端与商家端合并为同一小程序交付。

- 小程序 AppID：`wx1d1452c2f59ffa68`
- 云环境 ID：`cloudbase-d6gny18wlbad9e070`

## 技术架构

- 前端：原生微信小程序（WXML / WXSS / JavaScript），自定义 tabBar，漫画风 UI
- 后端：微信云开发（云函数 / 云数据库 / 云存储）
- 支付：微信云支付 `cloudPay`（统一下单 + 支付回调，数据库事务保证幂等）
- 开放能力：手机号快速验证组件、订阅消息（可选）

## 交易与资金流程

1. **二手交易**：买家在线支付 → 平台托管 → 商品标记已售出 → 自动生成订单记录（商家端可见）。货款结算给卖家的通道为待完善事项。
2. **互助交易**：发布者预付酬金（平台托管）→ 他人接单 → 发布者确认完成 → 接单者余额入账（平台抽取 15% 佣金）→ 生成订单。
3. **提现**：用户提交提现申请（银行卡号 + 持卡人姓名）→ 商家端审批 → 平台人工打款，拒绝时金额退回余额。

## 本地开发与部署

1. 使用微信开发者工具导入 `client/` 目录，确认 AppID 为 `wx1d1452c2f59ffa68`。
2. 确认云环境 ID 与 `app.js` / 各云函数中配置一致（`cloudbase-d6gny18wlbad9e070`）。
3. 创建数据库集合（见上表）。
4. 在 `cloudfunctions/` 下，将全部云函数逐个右键「上传并部署：云端安装依赖」。
5. 配置管理员：云开发控制台 → `config` 集合添加文档：

```json
{
  "_id": "admin",
  "openidList": ["你的openid"]
}
```

也可以在 `cloudfunctions/admin/index.js` 与 `config/index.js` 的 `ADMIN_LIST` 中直接填写 openid（需重新部署）。

6. （可选）订阅消息：在微信公众平台申请模板，填入 `client/config/templateIds.js` 与 `sendMessage` 云函数。

## 上线前检查

- 手机号登录需在小程序后台开通「手机号快速验证组件」权限。
- 云支付需完成商户号绑定，`pay` 云函数中的 `MERCHANT_ID` 为占位值，上线前替换为真实商户号。
- 云存储权限需设置为「所有用户可读」，否则他人无法查看上传的图片。
- 文档类功能需确认 `docs` 云函数已部署、文档集合已导入；外链文档需配置 downloadFile 合法域名。
- 提现为人工打款模式，需由商家端管理员在后台审批。

## 常见问题

- **云函数报 `Cannot find module 'wx-server-sdk'`**：未选择「云端安装依赖」，请重新部署。
- **部署报 `ResourceInUse.FunctionName`**：云上已有同名函数，先在云开发控制台删除后重新上传。
- **图片加载 500**：云存储权限未开放「所有用户可读」。
- **自定义 tabBar 角标不显示**：已改为组件内定时同步，无需处理。
- **金额异常**：发布端已做两位小数实时校验，服务端双重校验。
## 隐私与安全说明

- 银行卡号仅存于云数据库 `finance` 集合（完整卡号仅供商家端管理员审批打款使用）。
- 用户端与商家端界面展示均为脱敏格式（`6222 **** **** 1234`），用户端接口返回的卡号同样脱敏。
- 建议将数据库权限设置为「所有用户不可读写，仅云函数（管理端）可读写」，客户端全部读写均通过云函数完成。
